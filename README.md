## 전체적인 기능 흐름 

1. 입력 기능
2. 로또 발급 기능
3. 당첨 확인 기능 
4. 결과 계산 및 통계 기능
5. 출력 기능

<br>

## 📌기능 목록 
1. 입력 기능 
- [ ] 로또 구입 금액을 입력 받는다.
  - [ ] (예외) 입력값이 음수이거나 숫자가 아닌경우 에러메시지 출력
  - [ ] (예외) 입력값이 1000으로 나누어 떨어지지 않는 경우 에러메시지 출력
- [ ] 당첨 번호 6개를 쉼표로 구분하여 입력받는다.
- [ ] 보너스 번호 2개를 입력받는다.
- [ ] 예외발생시 에러문구 출력후, 해당 부분부터 입력을 다시 받는다. (이 조건은 모든 입력에 유효)
  
<br>

2. 로또 발급 기능
- [ ] 구입 금액에 맞는 수 만큼 로또를 랜덤으로 발급한다. (각 숫자는 1~45의 랜덤숫자 6개, 중복 없음) 

<br>

3. 당첨 확인 기능
- [ ] 랜덤으로 구매한 각 로또와 당첨번호를 비교하여 당첨유무를 확인한다.

<br>

4. 결과 계산 및 통계 기능
- [ ] 총 당첨 금액을 계산한다.
- [ ] 구입 금액과 당첨 금액을 비교해 수익률을 계산한다.(소수점 둘째 자리에서 반올림)

<br>

5. 출력 기능 
- [ ] 금액에 맞게 발급한 로또 개수를 출력한다.
- [ ] 랜덤으로 발급한 로또 번호 6개를 오름차순으로 정렬하여 출력한다.
- [ ] 당첨 통계와 수익률을 출력한다.
- [ ] 예외 발생시 에러문구를 출력한다. (단, 에러 문구는 "[ERROR]"로 시작해야 한다.)
